### 7.1 What We Collect
- **Discord user data:** User ID, username, linked in-game name, coin balance, transaction history, daily bonus claims.

### 7.2 How We Use Data
- To display player stats, killfeeds, and leaderboards.

- All data is stored on our server in JSON format. We do not use third-party analytics, advertising networks, or data brokers.

Your Deadside server SFTP credentials are stored in a configuration file on our server. They are used solely to read kill logs and are never shared, transmitted, or used for any other purpose. We recommend using a dedicated SFTP account with read-only access where possible.
